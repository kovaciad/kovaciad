## What I'm building

### Claude desk companion
An ESP32 desk device that sits next to my computer and works with Claude Code. A small screen shows a live dashboard while Claude runs (cost, token usage, current model, number of agents) next to a pet, and switches to a question view when Claude needs an answer. A rotary encoder with a push switch (a haptic dial later on) picks answers and approves tool use, with a couple of buttons beside it. A bridge process, prototyped in Python and headed for Rust, connects the device to the computer.

*Status: prototyping.*

### Room automation
Presence detection for my room using BLE, built around an nRF52840 and a Qorvo DW3000. When I walk in, it can control a smart fan over IR and wake my PC with Wake-on-LAN. I'm also designing a custom wall-mount holster with a locking mechanism for a charging connector.

*Status: in progress.*
